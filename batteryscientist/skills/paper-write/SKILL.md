# 论文写作

- **输入材料**：读取 `PAPER_PLAN.md`、`refine-logs/FINAL_PROPOSAL.md`、`refine-logs/EXPERIMENT_PLAN.md`、`results/`、`figures/latex_includes.tex` 和现有论文源文件。
- **输出文件**：按计划写入 `paper/main.tex`、`paper/sections/*.tex`、`paper/references.bib`。
- **内容对应**：保持章节、主张、图表和证据之间的对应关系。
- **论文表达**：正文和附录均按论文语言组织，不在正文中堆砌实验日志、运行记录或工程检查。切勿写成**实验报告**。

## 语言与段落表达

- 使用本领域常见、自然的学术表达，直接说明研究对象、方法、结果及其含义。
- 将方案、实验报告和审稿意见中的内部术语转换为**面向论文读者的叙述**。

每段围绕一个明确问题展开，先陈述主要内容，再给出证据或解释。修订时重新组织整段论证，合并重复的限定和辩解；必要的定义在首次出现时说明，影响结论的局限集中讨论。表达调整保持事实、比较方向、统计含义及适用范围一致。

### 第 1 步：初始化项目

1. 创建`paper/`目录
2. 未指定会议或期刊时，默认使用 `templates/nature.tex` 作为 `paper/main.tex`，将 `templates/nature-citations.sty` 和 `templates/sn-nature.bst` 一起复制到 `paper/`。这是通用论文排版配 Nature 引用样式；指定投稿格式时改用相应模板。已有论文保留正文排版，未指定引用样式时接入相同的 Nature 引用配置。
3. 使用论文特定符号生成 `math_commands.tex`
4. 创建匹配 PAPER_PLAN 结构的节文件

默认通用稿使用 `\pagestyle{plain}`：无页眉，仅页脚居中页码；在 `\begin{document}` 后设置，附录沿用。`ctexart`中文方案默认启用章节页眉，未覆盖时会在图表页重复显示“D 训练、成本与可复现性”等附录标题。明确指定期刊时遵循期刊页眉规范。

**作者封锁（匿名模式）：**
```latex
\author{Anonymous Authors}
```

### 步骤2：生成math_commands.tex

根据论文的符号创建共享数学宏：

```latex
% math_commands.tex — 共享符号
\newcommand{\R}{\mathbb{R}}
\newcommand{\E}{\mathbb{E}}
\DeclareMathOperator*{\argmin}{arg\,min}
\DeclareMathOperator*{\argmax}{arg\,max}
% 在此处添加论文特定的符号
```

### 第 3 步：写下每个部分

按顺序处理部分。对于每个部分：

1. **阅读计划** — 读取本节的段落任务、主张、研究证据和引用计划，复用已核实来源及已有引用键。
2. **内容草稿** — 根据已有证据编写完整的 LaTeX，不编造缺失的数据或结果。
3. **插入 figures/tables** — 使用 `figures/latex_includes.tex` 中的片段及正式 caption；图注、表注保持简洁，修改统一更新该文件。
4. **同步添加引文** — 起草相关句子时使用引用计划中支持该论点的文献，并将实际引用的可靠元数据写入 `paper/references.bib`；默认 Nature 样式使用 `\cite{key}` 生成数字上标，按首次引用顺序编号；叙述作者时写作 `Severson等\cite{key}`，不用 `\citet` 自动生成作者名。指定 ML 模板时使用其支持的 `\citep` / `\citet`，IEEE 模板使用 `cite` 包和 `\cite`。

图表接入保持绘图阶段交付的完整组合图与子图分组，结合 `figure_plan.md` 的目标尺寸为图注留出空间。放不下时，先调整放置位置和保持文字可读的整图尺寸；仍无法适配时，将具体图号、页面可用宽高和问题反馈主控，安排绘图阶段重排整图。用户未明确要求拆分时，不自行用 `trim/clip` 裁切子图或用 `ContinuedFloat` 按行拆成续页；表格按内容需要跨页，不受组合图规则限制。

### 章节写作框架

全文围绕“问题—方案—证据—意义”展开。以电池、电解液和材料研究的任务、数据和证据为主。每节起草前，用 `battery_resources(action="read", resource_id="对应分节的 resource_id")` 读取下列指南；返回 `next_offset` 时续读，复用已读内容。

写作前明确研究对象、具体任务、现有不足、核心方案、验证证据与适用边界。区分文献事实、实证结果、假设与机理解释，统一对象、符号、指标及划分口径，区分电芯数、循环数、窗口数与测量点数。每段承担一个任务，以观点、依据和解释推进；按主张选择结果，不机械覆盖全部验证维度。

实际章节顺序遵循期刊要求；通常方法先于结果，Results 与 Methods 分设时可重排。数据集和“总结与讨论”正文各三段，其余句数与段数可按内容和篇幅调整。

- **摘要**：领域意义与具体困难 → 整体方案与关键思路 → 主要定量结果 → 研究意义。 参考[本节指南](../../../电池资源库/代码和绘图指南/论文写作/01-摘要.md)，resource_id：`代码和绘图指南/论文写作/01-摘要`。
- **引言**：具体需求 → 问题为何困难 → 已有路线及不足 → 可检验的研究缺口 → 核心洞见与贡献。 参考[本节指南](../../../电池资源库/代码和绘图指南/论文写作/02-引言.md)，resource_id：`代码和绘图指南/论文写作/02-引言`。
- **数据集**：按三段交代来源与覆盖范围、样本定义与预处理、数据划分与验证范围。 参考[本节指南](../../../电池资源库/代码和绘图指南/论文写作/03-数据集.md)，resource_id：`代码和绘图指南/论文写作/03-数据集`。
- **方法**：任务定义 → 整体框架 → 关键设计及作用 → 目标与约束 → 训练和使用流程。说明各模块如何衔接，并统一符号。 参考[本节指南](../../../电池资源库/代码和绘图指南/论文写作/04-方法.md)，resource_id：`代码和绘图指南/论文写作/04-方法`。
- **实验与结果**：比较设置 → 核心结果 → 与研究主张对应的泛化或设计验证 → 现象解释。每个结果段先说明发现，再用图表和代表性数字支撑，最后解释含义。 参考[本节指南](../../../电池资源库/代码和绘图指南/论文写作/05-实验与结果.md)，resource_id：`代码和绘图指南/论文写作/05-实验与结果`。
- **总结与讨论**：按三段组织核心发现与解释、领域联系与价值、局限与后续方向，作为论文末节。 参考[本节指南](../../../电池资源库/代码和绘图指南/论文写作/06-总结与讨论.md)，resource_id：`代码和绘图指南/论文写作/06-总结与讨论`。

Wiki 写作卡片帮助组织具体论证、转场和表达，search_writing_cards(query, limit=5)，起草论文前，以及其他章节存在论证组织、转场或表达问题时，按需检索 Wiki 写作卡片来参考相关领域中高质量文章的组织习惯和逻辑

以上作为起草框架，具体段落要求、表达方式和论证细节按各节独立指南落实。

### 第 4 步：引用补漏与参考书目整理

1. 对照 `PAPER_PLAN.md` 和正文补齐文献依据，复用已核实来源。缺口按关键词用 `search_wiki` 检索、`read_wiki` 阅读；Wiki 不足时用 `search_papers` 补充。
2. 新增文献用 `search_papers` 核对书目信息，优先采用正式发表版本，写入 `paper/references.bib`，并将支撑论点和来源链接同步到引用计划。
3. 整理正文引用与 `.bib`，合并重复论文，保留实际引用条目。正文至少引用 20 篇不同论文，不足时围绕相关论述补充，交付时报告实际篇数。
   统计从主入口实际加载的正文引用，排除注释、未加载文件、仅附录引用和 `\nocite`；同一论文的多个引用键只计一篇。书目条目数不等于正文引用篇数。已有计划不足时继续定向核实并同步补齐计划；负结果、材料足够或不凑数量均不能豁免这一要求。不足20篇时保存草稿并报告未完成，不能仅记录限制后宣称完成。
4. 默认使用 Nature 引用配置：`\usepackage{paper/nature-citations}` 和 `\bibliographystyle{paper/sn-nature}`，从项目根目录编译。`.bib` 保留完整元数据，作者缩写、标点和链接展示交给样式文件；指定期刊时遵循对应模板。
